## Известные проблемы

- `resize_window` из Chrome MCP возвращает успех, не изменяя окно. Проверять
  результат по размеру скриншота, а не по тексту ответа.
- `claude -p --permission-mode bypassPermissions` блокируется классификатором.
  Работает точечный `--allowedTools`.
- На машине работают чужие Docker-контейнеры (`mysql57`, `cards-api-*`,
  `cryptomus-*`, `univer-*`, `laravel-app-*`). Порт 3306 занят. Останавливать
  их нельзя.
- Сидовые данные не позволяют проверить пагинацию: максимум 8 постов в
  категории, контролы не появляются. Неоднозначность U5 в `SPEC.md` §10.
- Счётчик просмотров растёт от собственных проверок, из-за чего результаты
  `?sort=views` между прогонами не воспроизводятся дословно.
