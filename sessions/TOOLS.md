# Журнал инструментов

> Только дополняется, старые записи не редактируются. Сюда попадает всё, что вы
> добавили в проект или окружение ради этой задачи: библиотеки, CLI-утилиты,
> линтеры, MCP-серверы, плагины и скиллы агента, хуки, внешние сервисы, контейнеры.
>
> Разовый вызов уже установленного инструмента сюда не пишется — он идёт
> в таблицу инструментов внутри файла сессии.
>
> Тупиковая попытка — тоже запись: поставили, не подошло, сняли. Это как раз интересно.

## Шаблон записи

```markdown
## YYYY-MM-DD · Сессия N · <инструмент> vX.Y

- **Тип:** библиотека / CLI / MCP / плагин / скилл / хук / сервис
- **Установка:** `<точная команда>`
- **Зачем:** какую задачу решает
- **Область:** проект или глобально
- **Проверка:** чем убедились, что работает
```

Удалённый или заменённый инструмент фиксируется так же — с пометкой
**удалён** / **заменён на X** и причиной.

## 2026-08-17 · Сессия 2 · mattpocock-skills v1.2.3 (скилл `grill-me`)

- **Тип:** плагин Claude Code (набор скиллов)
- **Установка:** `claude plugin install mattpocock-skills`
- **Зачем:** просили «grillme mcp». MCP-сервера с таким именем не существует —
  под этим именем есть скилл `grill-me`: интервью-допрос, который заостряет план
  или дизайн до начала реализации. Сам `grill-me` состоит из одной строки и
  делегирует работу скиллу `grilling`, поэтому ставился весь набор.
- **Область:** глобально (scope: user). В репозиторий проекта ничего не добавляется,
  файлы лежат в `~/.claude/plugins/cache/claude-plugins-official/mattpocock-skills/1.2.3/`
- **Проверка:** `claude plugin list` → `enabled`; `find` нашёл
  `skills/productivity/grill-me` и `skills/productivity/grilling` на диске;
  чистая сессия `claude -p` подтвердила `grilling` в списке скиллов.
  `grill-me` в списке модели отсутствует **штатно** — у него в frontmatter
  `disable-model-invocation: true`, он вызывается только человеком через `/grill-me`.
- **Заметка:** в README репозитория команда написана как `claude plugins install`
  (мн. ч.) — такой команды нет, работает `claude plugin install`.
- **Побочный эффект:** вместе с `grill-me` приезжает весь набор (~30 скиллов).
  Выборочная установка невозможна; снимается целиком через
  `claude plugin uninstall mattpocock-skills`.

  ради пакета, без которого можно обойтись

## 2026-08-17 · Сессия 3 · Docker Compose (стенд объекта тестирования)

- **Тип:** сервис/окружение
- **Установка:** `docker compose build && docker compose up -d` в клоне
  `app-under-test/`; затем `composer install`, миграции, сидер, компиляция SCSS
- **Зачем:** поднять объект тестирования — PHP 8.3 + MySQL 8 + Nginx + Smarty
- **Область:** локально, контейнеры проекта `app-under-test`
- **Проверка:** `Seeded 6 categories. / Seeded 25 posts. / === STAND READY ===`,
  затем `curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/` → `200`
- **Тупик, который пришлось обойти:** порт 3306 занят чужим контейнером
  `mysql57` (работает 11 дней, останавливать нельзя). Правка
  `docker-compose.yml` объекта запрещена правилами. Решение — отдельный
  `docker-compose.override.yml` с `ports: !reset []`: приложение ходит в базу
  по внутренней сети Compose, наружу порт не нужен вовсе. Compose v2.35.1
  синтаксис `!reset` поддерживает

- **Важно для чистоты прогона:** наивная сессия запускалась **из нейтральной
